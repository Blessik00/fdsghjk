# PulsePvP 1.1.0 (Fabric, Minecraft 1.21.4)
Исходники мода. Сборка: `./build.sh` (нужна Java 21) или вкладка Actions на GitHub.
- `src/` — исходный код новых/изменённых классов
- `original/` — исходный pulsepvp-1.0.0.jar (из него берутся Hud, Tracker, DamageNumbers, Ui)
- `stubs/` — заглушки API Minecraft только для компиляции (в jar не попадают)
